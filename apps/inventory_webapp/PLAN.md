# Inventory Review Webapp — Plan

**Linear:** [GR-6](https://linear.app/dentaway/issue/GR-6/webapp-for-inventory-review-and-summary-from-sqlite-excel-take-off)

**Goal:** A local webapp that lets an estimator select a project, review per-drawing inventory (approve / exclude / amend), view source PDFs (with overlays when available), and see summaries by floor or by category. No rates, labour or costs in this slice.

## Scope (this PR)

- SQLite project + drawings + inventory items (seeded from the Hubby Excel or `floors.json`)
- Streamlit UI:
  - Project picker
  - Drawing / floor picker
  - Inventory table with status (approved / excluded / amended) and editable fields
  - Summary views: by floor, by category
  - Placeholder PDF viewer (link or embed when PDF path is known)
- Persistence of review decisions in SQLite
- Out of scope: costs, labour, Drive sync, full overlay rendering, auth

## Data model (SQLite)

```sql
CREATE TABLE projects (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL,
  code TEXT,
  notes TEXT
);

CREATE TABLE drawings (
  id INTEGER PRIMARY KEY,
  project_id INTEGER REFERENCES projects(id),
  floor_tab_name TEXT,
  drawing_number TEXT,
  title TEXT,
  scale TEXT,
  source_pdf TEXT,          -- path or Drive id later
  overlay_pdf TEXT
);

CREATE TABLE inventory_items (
  id INTEGER PRIMARY KEY,
  drawing_id INTEGER REFERENCES drawings(id),
  line TEXT,                -- A01, B01, H1 ...
  category TEXT,
  annotation TEXT,
  linked_to TEXT,
  count REAL,
  unit TEXT,
  size TEXT,
  tender_estimate REAL,
  measurement_type TEXT,    -- printed / scaled / geometry / vertical / specified-not-drawn / excluded
  scope TEXT,               -- in / interface / out
  notes TEXT,
  status TEXT DEFAULT 'pending',  -- pending / approved / excluded / amended
  amended_count REAL,
  amended_notes TEXT,
  reviewed_at TEXT
);
```

## User flow

1. Open app → select project (Hubby Premier Inn Putney is seeded).
2. Sidebar: list of drawings / floors.
3. Main: inventory table for selected drawing. Checkboxes or buttons for Approve / Exclude. Inline edit for count / notes.
4. Summary tab: pivot by floor or by category (sum of approved tender quantities).
5. PDF: if `source_pdf` is set, embed or link; overlay PDF shown side-by-side when present.

## Implementation notes

- Streamlit chosen for speed of MVP and because the extractor is already Python. Later can be replaced by a Next.js frontend calling a FastAPI that reuses `riser_extract`.
- Seeder reads the Excel workbook (or the evals `floors.json`) and populates the tables.
- Amber / inferred rows are flagged via `measurement_type != 'printed'`.
- First Floor is marked as interpolated.
